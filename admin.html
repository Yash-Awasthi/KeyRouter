KeyRouter

Wrap a provider key in a disposable key that expires on its own.

Real API keys are stored unencrypted. Set the ENCRYPTION_KEY secret (see the README) so new and edited keys are encrypted.
This is a read-only viewer account: you can see keys, usage and prices, and you cannot create, edit, revoke or export anything.
Provider down: . Calls to those keys will fail until the provider answers again.
This deployment has no passkey, so the admin password is the only thing protecting every key. Keys cannot be created until you add one below, unless the ALLOW_PASSWORD secret is set to true for a password-only deployment.

Limits (leave empty for none)

Spend and token caps are enforced only where the provider reports token usage: /messages, /chat/completions, /responses, /completions, /embeddings and Gemini's :generateContent. Any other POST path (audio, images, batches, files) is refused with a 403 for a key with a cap. The requests-per-minute limit and the allowed-IP list apply to every path.

Requests already running finish on their model; only new requests are rerouted.

Time window (leave all days unticked for any time)

A window that ends before it starts runs past midnight. Same start and end means the whole day.
